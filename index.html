Usage

Keep: Click on a dice to toggle "keep" mode. Kept dice won't be rolled when you click Roll, and they will have a green border.

Save: Use the Save button to store your current dice setup. You'll be asked to enter an ID. Later, you can reload your saved dice using the URL with ?id=yourid.

Dice Config (URL): You can set up dice directly by using the ?dice= query parameter in the URL.

Each configuration follows this format: [optional color]D[sides]. A color (hex code) applies to all following dice until a new color is specified.

If you want to specify a color, use a # before the dice (URL-safe, you can use | instead of # when writing URLs).

Examples:

  • ?dice=D6D8D20 → Adds a D6, D8, and D20 dice with the default color.
  • ?dice=#00ff00d6d10d12 → Adds three dice (6, 10, and 12 sides) all in green (#00ff00).
  • ?dice=#00ff00d6|ff0000d12d10 → Adds:
    • • A 6-sided dice with green (#00ff00)
    • • A 12-sided and 10-sided dice with red (#ff0000)

Important: The color applies to all dice following it until a new color is specified. Use | instead of # when writing URLs manually to avoid encoding issues.
